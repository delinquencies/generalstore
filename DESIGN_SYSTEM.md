# Stitch design notes

The ZIP contains one homepage HTML document, one 295 × 1600 desktop reference screenshot, and two Markdown documents. No independent product image files, mobile mockups, or standalone JavaScript files are present. The HTML loads Google Fonts, Material Symbols, Tailwind CDN with Forms and Container Queries, and 18 hosted image URLs. The application compiles Tailwind and removes Stitch's inline scripts.

The homepage HTML and screenshot take precedence over `curio_co._architectural_general_store/DESIGN.md` for visual decisions. That companion document has darker earth tones, stricter square shapes, and editorial spacing that differ from the rendered homepage. The mission-critical merchandising document informed the essentials assortment. Its replenishment subscription and New York courier details are future concepts.
